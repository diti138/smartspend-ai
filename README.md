# 💰 SmartSpend AI

## Intelligent Personal Finance Controller

SmartSpend AI is a simple AI-powered personal finance management application that helps users track and understand their daily expenses.

## 🚀 Features

- Add and manage daily expenses
- Categorize expenses such as Food, Travel, Shopping, Bills and Entertainment
- View total expenses
- Analyze category-wise spending
- Visualize spending using charts
- Identify the highest spending category
- Get smart spending insights and recommendations

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas

## 🎯 Project Objective

The objective of SmartSpend AI is to help users manage and understand their finances more effectively. The application analyzes spending patterns and provides useful insights to support better financial decisions.

## 💡 Problem It Solves

Many people struggle to track where their money is being spent. SmartSpend AI organizes expenses into categories, identifies spending patterns, and provides insights that help users understand and manage their budget better.
